# 发布前隐私检查

检查范围为公开项目中的源码、构建脚本、说明文件、演示图片和最终 EXE，不扫描或上传开发工作区中的其他文件。

## 已采取的处理

- 使用独立项目目录和新的 Git 历史，按白名单加入文件。
- 预览和测试只使用通用演示网卡及文档样例地址。
- 移除旧版读取真实网卡后直接导出诊断列表或截图的调试入口。
- `--render-demo` 和 `--self-test` 的截图入口强制使用演示网卡，两种模式均不读取本机网卡。
- 编译关闭调试符号，使用相对源码路径，不打包 PDB、个人路径、日志、测试输出或历史截图。
- 提交作者使用 GitHub 的 noreply 地址，不公开私人联系方式。
- 使用 `scripts/privacy-check.ps1` 检查公开文件与 EXE 的 ASCII、UTF-8、UTF-16 字符串及样例地址。

## 程序运行时

程序在本机读取网卡名称、接口 GUID、当前和永久 MAC。界面显示这些信息是选择和核对网卡所需的功能；这些运行时信息不会写入 EXE 或发送到远程服务。

应用地址前，程序将恢复所需配置保存在本机注册表的 `SOFTWARE/MacAddressTool` 下。该记录只留在当前电脑，工具不会将它纳入源码或发布包。

## 检查边界

静态扫描只能检测已知隐私格式和显式字符串，不能证明任意未来输入或任意外部文件都不含隐私。发布只允许白名单文件；实际网卡截图、测试机器的运行日志和个人诊断输出始终不公开。

IEEE 数据中的组织名称属于公开登记数据，不是用户的网卡信息。该数据仅保留厂商登记，不包含源 CSV 的邮寄地址字段。
